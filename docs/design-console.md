# 策划控制台

规则与奖励、装备与成长使用子页签。波次预览从右下角展开。难度曲线采用 Core 的生成公式；基准血量、有效秒伤由策划输入，输出时间不含移动和整备，不能作为实测通关时间。

## 游戏中文目录

页面已内置 2026-11-13 从 Instance1 实机导出的 7,651 条中文记录（武器 3,980、防具 1,614、装饰品 244、道具 1,813），过滤原生占位名称。默认无需手动导入。

需要刷新目录时，运行中的游戏实例可执行导出：

```powershell
node cli/mhr.mjs game run-script reframework/autorun-probe/export_design_catalog.lua --base-url "$env:MHR_IN1" --json
```

将游戏 `reframework/data/rogue_design_catalog.json` 导入装备抽取池或商店的目录面板。导出使用游戏当前语言；中文客户端才会得到中文名。目录仅创建临时对象读取名称，不添加任何装备或道具。各类目录无法解析时会记录 errors；本次导出四类均成功返回，但不应把目录存在视为每件装备或道具均已通过发放验证。首次导出后推进标题发生原生崩溃，原因未确认；重启后不重复运行探针，目录直接使用已导出的数据。

装备支持搜索、点击添加、拖入抽取池与名称选择。开局防具按系列头部名称选择，五部位仍由提交时的游戏校验决定。道具会添加为 native_item_数值ID，发放前仍检查原生枚举和背包可携带性。商店支持分类、名称、价格、数量限制和开放层段；移除补给正在引用的商品需先处理补给引用。

## 装备箱

右侧显示各部位的本局穿戴记录，点击筛选左侧，左侧点击装备发送原有 wear 命令；整备限制和版本校验保留。没有本局记录的槽位不会推断为原生装备。珠子通过真实槽位镶嵌，卸下回到本局库存。丢弃仅触发 discard-request 事件，参数为 equipmentKey/equipmentVersion，尚无实际删除操作。
