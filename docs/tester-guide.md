# 联机入场实验：两人测试与反馈

本次先验证：房主在网页选怪，朋友自动准备相同任务，通过游戏任务板加入，双方进入同一斗技场。完整多人肉鸽、续波、商店和奖励同步尚未实现。真实双客户端共同入场仍待验证；网页“准备一致”不等于联机通过。

## 安装：两人必须用同一份包

1. 从 Releases 的 **Nightly — 最新联机入场实验版**，下载 Assets 里的 **MHR-Arena-Roguelike-nightly.zip**。不要下载 Source code。每天北京时间 04:00 开始构建，也可由维护者临时构建；只有检查成功才更新下载。
2. 链接显示 404 或要求权限时，让测试组织者直接把 ZIP 发给你：目前私有仓库不向未授权访客开放下载。
3. 两个人都完全退出游戏。按“使用说明.txt”先备份存档，再把包内文件解压到 **MonsterHunterRise.exe 所在文件夹**，不是另建一层文件夹。覆盖旧文件，不要在游戏开启时换 DLL。
4. 双方使用各自 Steam 账号和拥有游戏的电脑，保持游戏、Sunbreak 与模组版本一致。组织者发送同一份 ZIP，避免 nightly 在两人下载之间更新。
5. Steam 启动游戏，默认浏览器会自动打开控制台；未打开时双击包内“打开电脑控制台.url”，或在浏览器地址栏输入 **http://localhost:11777/console**。等角色进入村庄后再操作网页。

## 一起测试

1. 两人选自己的存档进入村庄。如果有上局装备、背包恢复提示，先完成恢复，不要带着未结束的单人局测试。
2. 房主在游戏内通过邮差建立仅供约好朋友测试的在线大厅；朋友用游戏菜单加入。确认游戏大厅里确实有两个人。网页不是联机入口，不要把房主的 localhost 发给朋友。
3. 各自打开自己电脑的网页，选“联机入场测试”。应分别显示“大厅房主”和“大厅队员”。如果网页未看到大厅，正常退出大厅再重建／加入，让模块观察到新的 Steam 大厅事件。
4. 房主先选单怪。朋友不用任务码；等双方页面都列出两个 Steam 成员，全部“准备一致”。朋友未准备好时，可点“重试自动同步”；不要绕过灰色按钮。
5. 房主点“承接大厅任务”。再次全队确认后打开原生任务柜台，按游戏提示完成接取。拒绝或超时不要反复点，先下载日志。
6. 朋友在游戏原生任务板加入房主的 **MP ENTRY TEST / 联机入场测试**，编号 900103，不是单人任务 900102。
7. 两人确认游戏参战列表及准备状态，准备完成后房主在游戏内手动出发。网页不会替队员准备或自动出发。
8. 进斗技场先不打怪，双方确认看见彼此、对方会移动、怪种数量相同，再各打几下确认都能参战。有条件录两个视角。
9. 用游戏菜单正常完成或返回村庄。单怪通过后另开任务测试顺序双怪及同时双怪。顺序波第一只死亡前不应出第二只，同时波应能看到两只活怪同场。

不要用单人“开始”、mock 队友、kill-all、无敌和 PT 商店代替联机验证。换房主、断线恢复、跨波奖励也不属于本次已验证能力。

## 不懂电脑也能发反馈

出问题先保留现场，双方各点网页上方 **下载测试日志**。浏览器下载列表会出现 **MHR-support-日期时间.json**，把两个文件发给组织者，附游戏画面，说明卡在第几步、谁是房主。

日志含版本、当前状态、最近操作和每份最多 128 KB 的日志尾部，可能含 Steam 玩家标识、电脑路径和网络信息，请私下发维护者，不要公开上传；不含存档、密码。缺失文件会注明；旧文件可能属于上一局，要以实时状态和截图对账。

崩溃或网页完全打不开时不能下载：先拍错误画面，记录发生时间，联系组织者。不要自行删存档或关闭整个防火墙。

## 手机控制：可选，与朋友入场无关

1. 手机连接与自己电脑同一路由器的 Wi-Fi，电脑插网线也可。这就是“同一个局域网”。只开流量不行，访客 Wi-Fi 也可能不行。
2. 电脑首页显示手机完整地址，例如 **http://192.168.1.25:11777/console**，原样输入手机浏览器地址栏。不能在手机输入 localhost、127.0.0.1 或 0.0.0.0。
3. 手机上不再显示这条连接提示。换 Wi-Fi 后可在电脑点“刷新手机地址”。
4. 电脑能开、手机不能开时，查看首页防火墙帮助或“使用说明.txt”：家庭专用网络允许游戏通过防火墙，必要时仅放行本地子网 TCP 11777。不要关闭整个防火墙，不做公网端口转发。
5. 朋友在另一所房子，使用自己的游戏和网页；朋友间的联机由 Steam 完成。
