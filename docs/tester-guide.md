# 联机多波次实验：两人测试与反馈

本次验证完整主线：入队和出发 → 清波 → 返回起点集结 → 各自购物 → 房主选下一波 → 同场继续。本机双真实引擎已验证这条流程、共享猫车及失败回村，使用本地模拟 Steam 传输；不同电脑官方 Steam 仍待验证。网页“准备一致”不等于战斗同步通过。无需开启调试模式。

双方必须安装同一个 Nightly，使用相同配置。每人先选初始套装；房主选波后，双方自动备份并清空本局物资、穿戴初始套装，各获150 PT。第一波正常发奖励，原装备和背包在局末恢复。

## 安装：两人必须用同一份包

1. 从 Releases 的 **Nightly — 联机多波次实验版**，下载 Assets 里的 **MHR-Arena-Roguelike-nightly.zip**。不要下载 Source code。每天北京时间 04:00 开始构建，也可由维护者临时构建；只有检查成功才更新下载。
2. 链接显示 404 或要求权限时，让测试组织者直接把 ZIP 发给你：目前私有仓库不向未授权访客开放下载。
3. 两个人都完全退出游戏。按“使用说明.txt”先备份存档，再把包内文件解压到 **MonsterHunterRise.exe 所在文件夹**，不是另建一层文件夹。覆盖旧文件，不要在游戏开启时换 DLL。
4. 双方使用各自 Steam 账号和拥有游戏的电脑，保持游戏、Sunbreak 与模组版本一致。组织者发送同一份 ZIP，避免 nightly 在两人下载之间更新。
5. Steam 启动游戏，默认浏览器会自动打开控制台；未打开时双击包内“打开电脑控制台.url”，或在浏览器地址栏输入 **http://localhost:11777/console**。等角色进入村庄后再操作网页。

## 一起测试

1. 两人选自己的存档进入村庄。如果有上局装备、背包恢复提示，先完成恢复，不要带着未结束的单人局测试。
2. 房主在游戏内通过邮差建立仅供约好朋友测试的在线大厅；朋友用游戏菜单加入。确认游戏大厅里确实有两个人。网页不是联机入口，不要把房主的 localhost 发给朋友。
3. 各自打开自己电脑的网页，选“联机大厅”。应分别显示“你是房主”和“你是队友”。如果网页未看到大厅，正常退出大厅再重建／加入，让模块观察到新的 Steam 大厅事件。
4. 各自选择初始套装，再由房主选单怪；个人准备完成后打开开局商店，用初始150 PT买药。朋友不用任务码；等双方页面都列出两个 Steam 成员，全部“准备一致”。朋友未准备好时，可点“重试自动同步”；不要绕过灰色按钮。
5. 房主点“承接大厅任务”。再次全队确认后打开原生任务柜台，按游戏提示完成接取。拒绝或超时不要反复点，先下载日志。
6. 朋友在游戏原生任务板加入房主的 **MP ENTRY TEST / 联机入场测试**，编号 900103，不是单人任务 900102。
7. 两人确认游戏参战列表及准备状态，准备完成后房主在游戏内手动出发。网页不会替队员准备或自动出发。
8. 进斗技场先不打怪，双方确认看见彼此、对方会移动、怪种数量相同，再各打几下确认都能参战。有条件录两个视角。
9. 单怪通过后继续同场选波，测试顺序双怪及同时双怪。顺序波第一只死亡前不应出第二只，同时波应能看到两只活怪同场。

不要用单人“开始”、mock 队友、kill-all、无敌和 PT 商店代替联机验证。本机2/3/4真实引擎已经验证入场、跨波奖励、购物/抽取隔离、原生三猫失败与恢复保存。普通武器已有双端伤害与三端死亡复制样本，捕获已有原生强制捕获状态复制样本；完整武器矩阵、手动陷阱/麻醉流程、官方Steam跨电脑与长局仍需验证。当前不支持局内换房主或中途加入/离开，队伍变动会结束本局；结束恢复后可以重新组队开新局。

## 不懂电脑也能发反馈

出问题先保留现场，双方各点网页上方 **下载测试日志**。浏览器下载列表会出现 **MHR-support-日期时间.json**，把两个文件发给组织者，附游戏画面，说明卡在第几步、谁是房主。

日志含版本、当前状态、最近操作和每份最多 128 KB 的日志尾部，可能含 Steam 玩家标识、电脑路径和网络信息，请私下发维护者，不要公开上传；不含存档、密码。缺失文件会注明；旧文件可能属于上一局，要以实时状态和截图对账。

崩溃或网页完全打不开时不能下载：先拍错误画面，记录发生时间，联系组织者。不要自行删存档或关闭整个防火墙。


## 进入斗技场后怎样继续

1. 双方各自在自己的电脑打开 `http://localhost:11777/console`。进入斗技场后，“当前局”的状态栏应分别显示“联机 · 房主”和“联机 · 队友”。
2. 一起击杀初始目标。先别点停局。剥取后两人都回到**刚进任务的出生起点**，原地等几秒；不需要回村。
3. 房主、队友各自查看“游玩”页，应显示相同层数和三个选项。只有房主能选择；队友按钮不可用是正常的。
4. 各自在自己的网页买一件蜂蜜或回复药，检查自己的 PT 扣款和自己的游戏背包。不要都连到房主的网页购物；那会操作房主的钱包。
5. 大家买完、保持集结后，房主选择下一波。状态显示等待同步时先不要重复点击。每台客户端登记相同 UID/槽位后才开始原生加载。
6. 先选 Single。两人确认看到同一只怪、都能打到，死亡后各自获得相同奖励一次。
7. 下一层选 Sequential：第一只死亡后第二只出现，杀第一只时不能提前发整波 PT。
8. 再下一层选 Simultaneous：先别打死第一只，确认双方都能看到两只同时活着；全部击杀后只发一次奖励。
9. 若卡住、怪物只有一方看得到、UID 不一致或网页显示停止，同一时间双方都点击“下载测试日志”，一起发给组织者。记下层数和选项，不要先重置脚本。

一局结束后，先等双方完成原生结算、保存并实际回村；等待装备和背包恢复完成，网页会自动开放下一局，可直接重新选波承接，无需 Reset scripts。

如果游戏提示“长时间未操作，已断开连接”，原生大厅已变化。网页会显示这条游戏提示，可点“关闭游戏提示”；随后在游戏信使处重新创建/加入大厅，确认成员与房主后再准备。控制台显示“已连接游戏”仅表示遥控器仍能联系本机游戏。已有四端断线后重新入厅、不Reset再开局的样本，不能把它当作原厅从未断线。

当前不支持中途加入/离开或房主迁移，固定队伍发生变化会停止。配置不一致在承接前拒绝；两端版本或配置变化后请全队回村重新开局。网络迟迟未确认会超时停止，不会自动让大家重进不同任务。攻击、防御、会心强化均限定本机玩家，只在下一波生效。共享猫车恢复由房主购买；装备抽取的局末清理仍应结合双方日志检查。

## 手机控制：可选，与朋友入场无关

1. 手机连接与自己电脑同一路由器的 Wi-Fi，电脑插网线也可。这就是“同一个局域网”。只开流量不行，访客 Wi-Fi 也可能不行。
2. 电脑网页的“帮助与连接”显示手机完整地址，例如 **http://192.168.1.25:11777/console**，原样输入手机浏览器地址栏。不能在手机输入 localhost、127.0.0.1 或 0.0.0.0。
3. 手机上不再显示这条连接提示。换 Wi-Fi 后可在电脑点“刷新手机地址”。
4. 电脑能开、手机不能开时，查看“帮助与连接”中的防火墙帮助或“使用说明.txt”：家庭专用网络允许游戏通过防火墙，必要时仅放行本地子网 TCP 11777。不要关闭整个防火墙，不做公网端口转发。
5. 朋友在另一所房子，使用自己的游戏和网页；朋友间的联机由 Steam 完成。


## 开局商店和个人装备

1. 在同一个大厅、尚未承接任务时，各自在网页“联机大厅”选自己的骨套/铁套。
2. 房主选择 Single、Sequential 或 Simultaneous。看到个人准备完成后，网页自动进入开局商店；也可点“开局商店”。
3. 每人用自己的150 PT购物；不要等第一波结束才买药。可以先承接/加入任务，仍可在出发前购物。
4. 抽取的是独立的临时装备。请在原生道具箱或营地帐篷更换，局末会回收本局条目并恢复原装。默认保留当前武器是现有开局方案；策划可指定初始武器。
5. 两人各自确认购物完成，再在游戏内准备、由房主出发。第一波正常计分，后续仍是剥取、起点集结、购物、房主选波。

## 专门验证三猫与重新开局

请让怪物实际打出猫车；全队共享三次，不要求每人各猫三次。第三次后应看到游戏的“任务失败”，而不是“任务完成”。随后等待自动结算、保存和实际回村，原装备/背包恢复后网页回到可开局状态，无需 Reset scripts。在同一个大厅再选波、购物、加入并出发，确认第二局能继续。

若出现恢复待办，先等恢复成功再换装或开始新局。若卡住，请双方从“帮助与连接”下载日志，说明画面是失败、完成还是仍在战斗；只说“回村了”不足以区分结束路径。
