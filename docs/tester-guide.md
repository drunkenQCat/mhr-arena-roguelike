# 联机入场实验：测试与反馈

本次只验证：真实 Steam 在线大厅的房主选怪，队友加入同一任务，一起进入斗技场并看见彼此与相同怪物。它不是完整多人肉鸽发行版，双客户端入场尚未验收，需要你和朋友协助测试。

## 准备

每位玩家都需要自己的 Steam 账号、拥有游戏的电脑，以及同版本游戏、Sunbreak 和本 Release。队友电脑也要安装本包。先按《使用说明》备份存档及旧模组。

一台电脑的两个网页不是两名玩家；网页只控制连接的那一个游戏。mock p2/p3 没有实体，不能参加本次验收。账号凭据不需要交给维护者。

游戏联机走 Steam，你们可以不在同一个家、不连同一个 Wi-Fi。手机控制自己电脑才要求同一家庭网络。朋友无需开放 11777 端口，也不要把端口暴露到公网。每人在自己电脑打开包内“打开电脑控制台.url”。

## 一、进入同一个大厅

1. 所有人进入自己的存档。之前跑过单人肉鸽的，先结束并回村，等网页不再提示装备／背包待恢复。
2. 约定一位房主。房主在游戏找信使，通过“联机游戏”创建大厅，设置密码或限制为约好的朋友。
3. 队友从游戏搜索大厅／好友加入。确认游戏大厅名单确实出现所有人，保持语音或文字沟通。
4. 各自打开网页“联机入场测试”。房主应显示“大厅房主”，队友应显示“大厅队友”。仍显示离线／身份不可用时不要继续，不要用单人开局按钮绕过。

## 二、房主选波，队友导入任务表

三个固定选项：单只镰鼬龙王；镰鼬龙王死亡后出现眠狗龙王；两只同时出现。此入口不应用肉鸽 HP、伤害和 PT 倍率。

1. 房主点一个选项，网页显示任务码，例如 MHR-ENTRY-1-S。
2. 房主把码发给所有队友。队友在自己的网页粘贴，点“准备任务表”。所有人确认本机显示的任务码完全相同。
3. 任务码是本版固定怪物表的编号，不会自动跨电脑传输，也不是大厅密码。队友未准备时，房主不要承接。换选项时先取消已接任务，让所有人重新准备。
4. 任务号 900103 独立于单人任务 900102。入口不会替换原装备／道具袋，不发 PT，不自动续波。

## 三、原生任务板加入与出发

1. 确认所有人的任务码相同后，房主点“承接联机任务（不自动出发）”，等游戏柜台关闭。拒绝／超时时查看操作记录，不连续重试。
2. 队友在游戏集会所任务板加入房主已承接的任务。任务标题应为 MP ENTRY TEST / 联机入场测试。
3. 所有人确认游戏参战名单齐全，各自准备。房主再从游戏内手动出发。网页不会提前出发或伪造准备状态。
4. 进图后先不杀怪，确认双方看见彼此猎人、地图相同，核对怪种／数量／出场顺序。随后各自攻击几次，确认可参战。
5. 使用游戏正常结束／返回流程。单人页“停止本局”、kill-all、无敌、PT 商店不是本次联机的结束／调试工具。

未接通：下一层选波同步、钱包商店、多人猫车、掉线重连、房主迁移、装备隔离恢复、全局奖励与持续波次。不要把“能一起入场”记录为“完整多人肉鸽通过”。

## 四、反馈什么

请分别记录两端：Release 版本、任务码、网页身份、游戏大厅人数、原生任务人数、能否加入任务、能否一起进图、是否看见彼此、实际怪种／数量、报错原文。网页“操作记录”可导出 JSON；另保存两端 /api/state 快照：浏览器将地址末尾 /console 改成 /api/state，保存页面。build-manifest.json 可核对构建。

提供原生任务板、参战名单、入场后双方视角截图。两端任务 unique 不要求人为改成一致，先通过大厅、参战名单与视角核对同一队伍。

找不到房主任务、显示无此任务、掉线、任务码不同或怪种不一致时，停止本轮并正常取消／退出，收集两端快照。不要运行猜测性的修复 Lua。分享前检查名字、IP、本机路径；不要上传存档、Steam 凭据或整个游戏目录。

当前实机证据：新版 Lua 已加载，离线身份正确，离线冒充房主选怪被拒绝。权限、任务码和集会所承接后不自动出发有离线自动测试。尚无两名真实在线玩家成功入场的证据，不能用 mock 或两个同账号进程代替。
