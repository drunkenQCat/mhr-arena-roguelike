# TypeScriptToLua 实机验证（2026-10-23）

环境：本机 Steam Rise 16.0.2.0，REFramework v1.5.9.1（5bae470）。
原始日志保存在 `.local/runtime-20261023/`，不提交完整机器日志。

## 实际复现与修复

1. 第一轮启动在配置校验抛错：随包 JSON 是 PascalCase，TS 接口是 camelCase。
   `validateConfig` 现在递归转换字段名，保留 A/B/C/D/AU 奖励标识；新增读取真实 JSON 的回归测试。
2. 第二轮启动报 `attempt to index a nil value (global 'Date')`。
   默认 RNG 种子改用可编译为 Lua `math.random` 的来源，显式传入种子的重放方式保留。
3. 第三轮确认 loaded、任务安装和 HUD；旧 free_arena 随后报告 ID 冲突。
   旧脚本现在识别两种 marker、核对任务属性后采纳，避免重复注册与 hook。
4. 检查实机加载的 bundle 发现 hook 回调的隐藏 self 参数和数组索引平移。
   pre/post 类型增加 `this: void`，原生参数表改为 `Record<number, unknown>`；
   使用宿主 `sdk.PreHookResult`，列表 hook 提供空 pre 回调。
   最终 bundle 确认是 `function(args)` / `function(retval)`，原生槽位仍为 `args[2]` / `args[3]`。
