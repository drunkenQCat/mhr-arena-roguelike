# v0.3.0-preview.2 · 商品效果与原生炼化测试版

此版本合并策划商品效果系统和原生防具傀异炼化，继续提供原有多人入场、同场多波次与个人商店。它是预发布测试版。

## 下载和升级

下载 Release 的 **MHR-Arena-Roguelike-v0.3.0-preview.2.zip**，不要下载 Source code。

1. 全队先退出游戏，备份存档，并在网页导出自定义配置。
2. 解压 ZIP，将其中内容复制到游戏目录，按包内“使用说明.txt”操作。
3. 全队安装同一包后重启游戏。本次升级包含 webconsole DLL 0.4.3，单点 Reset scripts 不能更新 DLL；旧客户端不能混入新版队伍。
4. 电脑打开控制台，手机访问和防火墙说明见网页“帮助与连接”。遇到问题时下载双方测试日志反馈。

## 主要变化

- **策划商品效果**：中文效果目录和参数表单，支持阶段、层数、武器、限购与同组上限；预览不执行游戏写入、不改变抽取随机序列。配置可导出 JSON 交接，效果规则下一局生效。
- **清楚的订单和余额**：下一波强化预留 PT，可在锁定前取消；原生应用核验后扣款。失败、交付未知、清理待办分别显示，未知结果不自动退款或重放。
- **多人效果事务**：房主统一确认全队名额，各玩家在自己的游戏内付款、交付与核验。包括未购买的成员在内，全队实际准备完成后才开放战斗。内建效果包括固定攻击加成、防御加成、发道具和装备抽取。
- **原生防具炼化**：本局临时大师位防具可花60 PT生成、比较并接受或保留结果；保留原生合法性与容量检查。炼化使用可用余额，不能花掉已预留给效果的 PT。
- **续波和恢复修正**：处理跨波延迟状态、旧强化清理与新交易的竞争；准备屏障跳过已讨伐或捕获的旧怪。修正原生保存成功后回执发布与业务会话轮换之间的竞争。

商品效果操作见包内“商品效果配置说明.txt”；没有配置商品时，可在“策划工作台 → 商品效果”新增，提交后重新开局。原生炼化入口在“局内装备箱”的防具详情；上位防具不支持该功能。

## 已验证及边界

新增效果事务已用**同机两个真实游戏进程、独立角色存档和模拟 Steam 身份**验证：全队限购竞争、取消后释放名额、个人道具与装备交付、首次入场准备屏障，以及同一任务内的单怪、顺序双怪、同时双怪。顺序第一只死亡不提前结束效果；完整清波后各端移除强化、只发一次奖励。从机真实猫车后恢复强化且不重复扣款；两端停止回村、恢复原资源并原生保存成功。另用独立浏览器验证多人异步预订和取消。

原有多人玩法曾完成2／3／4进程本机验收；**本次新增效果事务的原生实测人数为2**。不能由此宣称新增效果已通过3／4人、官方 Steam 跨电脑或长局验收。原生炼化的多人技能同步及候选确认中断后恢复仍待专项验证。

此前报告的一次非人工进程退出仍未归因，本版不宣称修复该退出。多人效果会话中途 Reset 后保留恢复记录，不支持运行中自动接管或重放旧许可；应先安全结束、回村恢复并完成原生保存。

安装包通过发布白名单和哈希检查，不包含研究探针、日志、存档、构建中间文件或模拟 Steam 组件。
