**核心判断**：机制骨架全部就位，缺的是**怪种池数据**和**古龙级怪种在斗技场的兼容性验证**。

Rise 对应物（傀异克服/冥渊龙）原生行为完整，总表 §7 的"地图机关缺失"问题在 Rise 侧不存在。

## 2. 兼容性证据与风险

### 2.1 有利证据

- **换怪生成已实测**：怪种探针（2026-10-27）在同一任务内用 `createEnemySetInfo` + 原生 RequestLoad 挂载了任意
  `_TypeValue`（60 青熊兽），完整走原生加载、可击杀、槽位释放复用。生成链路是 type 无关的。
- **模板 = 数据不是代码**：603 克隆 + `normalPatch` 注入 `_BossEmType/_BossSetParam` 表，bosses 数组直接填 id——
  换成 2072/2134 理论上就是"数据换一下"。
- **激昂金狮子 1303 / 嗟怨怨虎龙 1369** 在原生斗技场模板出现过（`arenaMonsterIds`），可立即入池。

### 2.2 风险（按严重度排序）

| # | 风险 | 说明 | 缓解 |
|---|---|---|---|
| R1 | **古龙级体型/AI 与斗技场几何** | 冥渊龙钻地机制、傀异克服的龙气状态、天廻龙飞行段——在围栏式小场地的行为未知；体型可能撞模型/出围栏 | 逐只探针：挂载→生成→拍照（体型）→强制致死→死亡事件；失败就隔离该怪 |
| R2 | **目标判定** | 原生 `_TargetType/BossEmType` 表驱动，理论上表换怪即可；但古龙任务的条件枚举（"讨伐"vs"狩猎"）与捕获语义需核对 | 探针读 `checkSendInventoryStatus` 同款思路：读回任务目标列表 |
| R3 | **实际血量不可控** | README 已知问题：新怪难度基础值走默认/回退链，乘法 hook 纠不了基础值——极强怪实际 HP 可能远低于策划 1.90 的预期 | 依赖难度链调查（总表 §3.1，独立工作流）；短期用 `ultimateHpFactor` 顶位并实测对表 |
| R4 | **任务成功结算** | 极强单怪 = 唯一目标，死亡即触发原生成功结算；M2 的"保留一只防提前结算"手段不适用于单怪波 | inplace 已有全灭结算拦截（M2c 实测过全灭不误结算）；单怪层需专门回归 |
| R5 | **掉落物落地** | 古龙剥取材料/珠子在斗技场的掉落物实体与拾取——未调查 | 低优先：策划掉落品质先接 gacha（M3.6 机制），原生掉落物后置 |

### 2.3 现有配置的两个小问题（顺手修）

- `unlockChain: 冥渊龙←爵银龙` 是**死配置**：`pickUltimate` 只过滤 `tier.ultimate` 列表，而冥渊龙不在其中。
- `ultimateHpFactor` 只在 `type==='AU'` 分支乘（run_core.ts:382），语义正确；但当前实际波次 HP 未经对表。

## 3. 数值链（诚实边界）

策划案"难度系数 1.90、血量 +1.1、PT 1.7x"中只有 **1.7x PT 和 +1.1 系数已在实现里**。
"难度系数 1.90"是 World 术语（任务难度表级），Rise 侧对应 `_VitalTbl/_AttackTbl/_Difficulty` 表选择 +
`QuestEnemyNando` 查询链——这条链目前**没打通**（README 已知问题：603 模板 VitalTbl=[68,68,80]，
单怪吃第一槽 68 而非 80；追加怪走默认/回退值）。

极强怪数值的**正确打开顺序**：
1. 短期：极强单怪把第一槽固定用模板最高难度档（normalPatch/inplace 表补丁加一条规则）+ `ultimateHpFactor`；
   实机记录实际 HP，与"标准血量×层数倍率×1.1"对账。
2. 中期：难度参数链调查（总表 §3.1 已列探针步骤），打通后极强系数进配置。
3. 策划案的 1.90 是终值诉求，不是实现输入——最终以实机对表为准。

## 4. 建议落地顺序

1. **P1 池子扩充（纯配置）**：1303/1369 立即入 ultimate 池（模板证据最硬）；修死配置（冥渊龙入池 + 解锁链生效）。
2. **P1 单只探针**：傀异克服天彗龙 2134（与已验证的天彗龙 1366 同模型同 AI 源，风险最低的 Risen）——
   inplace 换怪挂载 → 生成/体型/围栏/致死/死亡事件全链拍照 → 产出证据归档。
3. **P2 逐只扩池**：2134 通过后按 2075→2072→2073→2120→1412→135 顺序逐只探针入池（每只一个证据目录）。
4. **P2 击杀掉落触发**：`killWave` 处对 `tier==='ultimate'` 波次接一次 `gachaBuy('gacha_4')` 型发放
   （"古龙临时毕业装备"= 顶级池；机制 M3.6 已就绪，加触发点即可）。珠子/护石原生链路独立调查后置。
5. **P3 数值对表**：随难度链调查一并做。
