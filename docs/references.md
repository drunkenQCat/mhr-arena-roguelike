# Research references

- [REFramework](https://github.com/praydog/REFramework): supported game list, Lua scripting and plugin system, installation and release channel.
- [REFramework Lua game-name example](https://github.com/praydog/REFramework/blob/master/scripts/utility/RE8.lua): uses `reframework:get_game_name()`.
- [RiseQuestLoader](https://github.com/Fexty12573/RiseQuestLoader): companion quest editor and spawn editor.
- [Custom Quest Editing guide](https://github.com/mhvuze/MonsterHunterRiseModding/wiki/Custom-Quest-Editing): file format, quest loader, export/replace behavior, and multiplayer caveat.
- [Custom Spawn Editing guide](https://github.com/mhvuze/MonsterHunterRiseModding/wiki/Custom-Spawn-Editing): separate map spawn files and quest spawn-set references.
- [MHR-Overlay](https://github.com/GreenComfyTea/MHR-Overlay): example REFramework mod exposing monster/player/combat telemetry.
- [MHR-Overlay monster initialization issue](https://github.com/GreenComfyTea/MHR-Overlay/issues/58): documents a reported REFramework object/array issue during monster initialization.

These references establish that tools exist; they do not establish compatibility with the user's installed Rise build or prove dynamic spawning and wave transitions.
